個別指導 ことのは塾 さくら台校（架空の塾）

冬期講習の販促物一式

「冬期講習の生徒を集めたい。チラシと説明会の資料、Instagram の広告をまとめて頼みたい」という依頼を想定して作りました。
3 つの制作物で言うことと見た目をそろえ、印刷所にそのまま出せる PDF と、広告にそのまま入稿できる画像で納めます。日付や料金が変わっても、すぐに全部を差し替えられます。

01A4 両面チラシ入稿用 PDF・確認用 PDF 02説明会の資料16:9・8 ページの PDF 03Meta 広告バナー3 訴求 × 2 サイズ

01

A4 両面チラシ

新聞の折り込み・ポスティング・校舎での手渡し用。表で「この塾で何が変わるか」と特典、裏でコース・日程・申し込みの流れを伝えます。

  • 入稿用 PDF塗り足し 3mm 込み 216×303mm・2 ページ
  • 確認用 PDF仕上がり A4・2 ページ
  • 原稿の HTMLブラウザで開くと塗り足しの範囲も見えます

02

保護者説明会の資料

説明会でスクリーンに映し、そのまま配布もできる 16:9 の資料。離れた席からも読めるよう、本文は 20px 以上（注記を除く）・1 ページ 1 テーマにしました。

  • 資料の PDF16:9・8 ページ
  • 原稿の HTMLブラウザで開くと 8 ページを順に見られます

03

Meta 広告バナー（Instagram・Facebook）

訴求を変えた 3 案を、フィード（1080×1080）とストーリーズ（1080×1920）の 2 サイズで。広告の結果を比べて、反応のよい案に予算を寄せられるようにしています。

  • バナーの原稿（実寸の HTML）文言を変えて書き出し直せます

制作のポイント

3 つの制作物で、言うことをそろえる
「つまずいた単元までさかのぼる」「12/19 までの特典」「講師1人に生徒2人まで」を、チラシ・資料・バナーで同じ言葉と色にしました。広告で見た人がチラシや説明会で迷わないようにするためです。
印刷所にそのまま出せる PDF
チラシは仕上がり A4 の外側に塗り足し 3mm をつけ、文字は内側 10mm より内に置いています。確認用の A4 PDF も同時に書き出すので、校正のやり取りが楽になります。トンボなし・塗り足しのみで入稿できる印刷所を想定しています（トンボや CMYK の指定がある印刷所には合わせて調整します）。
差し替えに強い作り
チラシ・資料・バナーはすべて HTML と CSS で組み、スクリプトで PDF・PNG に書き出しています。日程や料金が変わっても、テキストを直して書き出し直すだけで全部そろいます。
広告の表示ルールにも気を配る
特典の締切は電話受付のある土曜日にし、「通常 22,000円」には対象の条件を添えました。実際の案件では、通常価格が実際に使われていた価格であることを確かめてから載せます。お客様の声には「個人の感想です」を付けています。
ストーリーズの見え方まで確かめる
縦長のバナーは、アカウント名や返信欄が重なる上下 250px に文字とボタンを置いていません。上の「範囲を表示する」で確かめられます。

架空の塾のデモです。名称・電話番号・料金・日程・声はすべて架空です。
