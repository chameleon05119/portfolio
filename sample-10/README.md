# sample-10：税理士事務所サイトのトップページ リニューアル（ほしの木税理士事務所）

7年以上更新が止まっていた、架空の税理士事務所のトップページを、スマホで読めて、料金が分かり、夜や休日にも予約できるサイトに作り直しました。課題の整理・構成・文章・デザイン・コーディングまで担当し、リニューアル前後を比べるページも作りました。

## ページ
| パス | 内容 |
|---|---|
| `index.html` | 比較ページ（最初の画面の重ね比べ・数字の比較・課題と改善・構成の変更・進め方） |
| `before/` | リニューアル前のサイト（よくある古いトップページを再現した架空のもの。`src/public/before/` をそのままコピー） |
| `after/` | リニューアル後のサイト（トップページ・個人情報の取り扱い） |

## リニューアル前の課題と、どう直したか
| 課題 | 直し方 |
|---|---|
| viewport の指定がなく固定幅 950px。スマホでは PC の画面が縮小され、本文は約 4.8px | スマホから組み直したレスポンシブ。本文 16px、予約ボタンは親指で押せる大きさ |
| 最初の画面が「親切・丁寧・迅速」だけで、誰のための何の事務所か分からない | 対象（個人事業主・フリーランス・小さな会社）と、相談のしやすさ（初回無料・オンライン・料金公開）を最初の画面に |
| 料金が「お問い合わせください」だけ | 3 プランの目安と条件、「どれを選べばいい？」の図解。追加費用は作業前に説明することも明記 |
| 業務内容が専門用語の箇条書き | お悩み → 立場ごと（個人事業主・開業前・会社・家族）のサービスのカードに |
| 連絡は電話・FAX・メールで平日の日中だけ | 24 時間の予約フォーム。前のサイトに書かれていなかった強み（オンライン相談は平日19時まで・土曜も）を前面に。スマホは画面下に「電話・予約」バー |
| 新着情報が 2019 年で止まり、長いあいさつ文 | お知らせは下に最新 3 件だけ。税理士の顔と短いメッセージ |

構成は「事務所が言いたい順」から、相談を考える人の疑問の順（自分に関係ある？ → 何をしてくれる？ → いくら？ → どう進む？ → どんな人？ → 予約）に並べ替えた。

## 数字（スマホ、2026年10月に計測）
| 項目 | 前 | 後 |
|---|---|---|
| スマホで見たときの本文の文字 | 約 4.8px（12px × 390 ÷ 980） | 16px |
| スマホ表示の指定（viewport） | なし | あり |
| Lighthouse 13.5 アクセシビリティ（モバイル） | 88（color-contrast・landmark-one-main） | 100 |

Lighthouse は 2 回計測して同じ値。ベストプラクティスは前後とも 100。パフォーマンスはどちらも写真がなく差が出ないうえ、計測のたびに揺れるので載せていない。SEO はデモとして noindex にしているので比べていない。

## 作りのポイント（リニューアル後）
- **予約ボタンだけ朱色**: 紺と緑のサイトの中で、押すところだけが目立つように。下に厚みを付けて押せるボタンに見せる
- **料金の図解**: 「会社ですか？」「記帳はご自身でできていますか？」の 2 問でプランが決まる
- **予約フォーム**: 入力し終えた項目からその場で確認し、送信時は最初のエラーの項目へ移動。デモのため送信はせず、受付のメッセージに切り替える（本番では送信先と自動返信メールを設定する）。JS が動かない環境では送信ボタンを押せないようにして電話を案内する
- **見出しを文節で折り返す**: `word-break: auto-phrase`（対応ブラウザだけ）
- **写真を使わない**: 事務所のシンボルの木・税理士・地図は SVG のイラスト。本番では写真と Google マップの埋め込みに差し替える

## 比較ページのスクリーンショット
`npm run shots` で、リニューアル前後の最初の画面（PC 1280×800・スマホ 390×844）と、課題ごとの切り出しを `src/public/shots/` に書き出す（ビルドしてプレビューを起動してから）。スマホは iPhone の Safari と同じく文字の自動拡大なしで撮る。

## 開発
```bash
npm ci
npm run dev
npm run build      # dist/ に出力
npx vite preview --port 5190 &
npm run shots      # 比較ページのスクリーンショットを撮り直す
```

動作の確認（全ページ・全幅のチェック＋予約フォーム・固定バー・比較ページのスライダーとタブ）。リニューアル前のサイトはわざと崩れているので対象から外す:
```bash
node ../../pj-chameleon/30_engineering/tools/site-check/check.mjs http://localhost:5190/index.html http://localhost:5190/after/privacy.html --exclude 'before/' --flows ./scripts/check-flows.mjs
```
