# sample-04：カフェ・喫茶店サイト（ひととき珈琲）

架空の喫茶店のサイトです。デザインからコーディングまで自作しました。

## ページ
トップ／メニュー／お知らせ（一覧・記事5件）

## 作りのポイント
- **納品しやすい形**: 素の HTML / SCSS（FLOCSS）/ JavaScript。ビルド結果は圧縮なし・固定ファイル名・相対パスで、`dist/index.html` を直接開いても動く
- **湯気のアニメーション**: 最初の画面の写真に、SVG の線で描いた湯気を重ねてゆっくり動かす。写真の切り取り位置をカップに合わせて固定し、PC（横長）でもスマホ（正方形）でもカップの上に来るようにしている
- **「本日の営業」と営業カレンダー**: 曜日と時刻から「営業中／定休日／営業時間外」を表示し、今月のカレンダーに定休日（毎週水曜・第3木曜）の色を付ける。臨時休業は `main.js` の日付の一覧に足すだけで反映される
- **喫茶店らしいメニュー表**: 品名と価格を点線でつなぎ、分類ごとに写真を左右交互に配置。上の分類ナビはヘッダーの下に固定し、今見ている分類を色で示す
- **アクセシビリティ**: スマホメニューは開いている間だけ背面を操作不可にし、Esc で閉じてボタンへフォーカスを戻す。店内写真の拡大はダイアログで、閉じたら押した写真にフォーカスを戻す。JavaScript が動かない環境でも内容がすべて読める
- **動き**: キャッチコピーが1行ずつ現れる、湯気、スクロールでの表示、写真のゆっくりした拡大。OS の「視差効果を減らす」設定では止める
- **画像**: WebP の幅違いを `srcset` で出し分け、`width`・`height` を指定して読み込み時のずれを防ぐ。最初の画面の写真は先読み

## 開発
```bash
npm ci
npm run dev
npm run build    # dist/ に出力
```

## 素材
- 写真: すべて [Pexels](https://www.pexels.com/ja-jp/license/)（商用利用可・クレジット表記不要）。出典の一覧は `src/assets/images/SOURCES.md`
- 地図: 架空の店のため簡易図を作成
- 店名・住所・電話番号・メニュー・価格はすべて架空です
