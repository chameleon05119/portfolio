# sample-03：中小企業コーポレートサイト（株式会社 柊精工）

架空の精密切削加工メーカーのコーポレートサイトです。デザインからコーディングまで自作しました。

公開ページ: https://chameleon05119.github.io/portfolio/sample-03/

## ページ
トップ／会社案内／事業・技術／お知らせ（一覧・記事4件）／採用情報／お問い合わせ（入力 → 確認 → 完了）／個人情報の取り扱い

## 作りのポイント
- **納品しやすい形**: 素の HTML / SCSS（FLOCSS）/ JavaScript。ビルド結果は圧縮なし・固定ファイル名・相対パスで、`dist/index.html` を直接開いても動く
- **共通部品**: ヘッダー・フッター・お問い合わせ欄は `src/_partials/` に1つだけ書き、ビルド時に各ページへ展開（納品物は普通の HTML）。今いるページのメニューには `aria-current="page"` が付く
- **お問い合わせフォーム**: 入力し終えた項目からその場で確認、エラーは項目の下に文字で表示し、送信時は一覧から該当の項目へ移動できる。確認画面の入力内容は HTML として解釈しない。デモのため実際には送信しない
- **アクセシビリティ**: スマホメニューは開いている間だけ背面を操作不可にし、Esc で閉じてボタンへフォーカスを戻す。募集要項のタブは矢印キーで切り替え。JavaScript が動かない環境でも内容がすべて読める
- **動き**: 縦書きのコピーが1行ずつ現れる、写真がゆっくり引いていく、数字のカウントアップ、スクロールでの表示。OS の「視差効果を減らす」設定ではすべて止める
- **画像**: WebP の幅違いを `srcset` で出し分け、`width`・`height` を指定して読み込み時のずれを防ぐ

## 開発
```bash
npm ci
npm run dev
npm run build    # dist/ に出力
```
