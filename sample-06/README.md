# sample-06：サービス紹介 LP（店舗向け SNS 集客ツール・ミセルポ）

カフェ・美容室など小さなお店向けの、架空の SNS 集客ツール「ミセルポ」のランディングページです。構成・デザインからコーディングまで自作しました。

## ページ
LP（トップ）／個人情報の取り扱い。無料登録・資料ダウンロード・ご相談は、ページの上に開くモーダルで受け付けます。

## 作りのポイント
- **納品しやすい形**: 素の HTML / SCSS（FLOCSS）/ JavaScript。ビルド結果は圧縮なし・固定ファイル名・相対パスで、`dist/index.html` を直接開いても動く
- **画像を使わない画面イメージ**: 最初の画面の管理画面とスマホの画面、特徴の中の画面（AI の文章案・投稿カレンダー・効果のグラフ）は HTML/CSS で組んでいる。グラフが伸び、スマホの中の投稿が流れ続け、「予約しました」の通知が出ては消える
- **マーケティングツールの LP の構成**: 数字と画面（最初の画面）→ 仕組みの図 → 特徴 01〜03（左右交互）→ 業種ごとの使い方 → 資料 → 効果シミュレーター → サポート体制 → 機能一覧 → 料金の比較表 → 導入事例 → よくある質問 → 3 つの入口（資料・無料・相談）
- **業種タブ**: WAI-ARIA の Tabs パターン（← → Home End で移動、選ばれていないタブは Tab で止まらない）。JS が動かない環境ではタブを出さず、4 業種を縦に並べる
- **効果シミュレーター**: 業種・フォロワー数・投稿回数で結果がその場で変わる（数字はなめらかに数え直す）。読み上げはスライダーを止めてから 1 回だけ伝える。JS が動かない環境では例の結果だけを見せる
- **料金の比較表**: 表として組み（見出しのセル・caption）、スマホでは横スクロールにして左の項目名の列を固定。キーボードでもスクロールできる
- **導入事例のスライダー**: scroll-snap で横に並べ、ボタン・点・スワイプで切り替え。自動では進めない。見えていない事例は `inert` にして読み上げ・Tab の対象から外す
- **モーダルのフォーム**: `<dialog>` を `command="show-modal"` で開く（JS が動かなくても開ける）。押したボタン（無料で始める／資料ダウンロード／相談する）に合わせて見出し・項目・完了の文言を切り替える。入力し終えた項目からその場で確認し、送信時は最初のエラーの項目へ移動。Esc・✕・背景で閉じ、閉じると押したボタンにフォーカスが戻る。スマホでは画面いっぱいに開く
- **スマホの追従ボタン**: 最初の画面を過ぎたら画面下に出し、ページ最後の入口が見えたら隠す
- **動き**: スクロールでの表示、数字のカウントアップ、お店の名前の帯（ボタンで止められる）、FAQ のなめらかな開閉。OS の「視差効果を減らす」設定ではすべて止める

```bash
npm run dev
npm run build    # dist/ に出力
```
