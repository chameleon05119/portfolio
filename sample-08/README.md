# sample-08：クリニックサイト（つむぎ整形外科）

架空の整形外科・リハビリテーション科のサイトです。デザインからコーディングまで自作しました。

## ページ
トップ／初めての方へ／診療内容／症状ページ（腰痛症）／リハビリテーション／医師・スタッフ紹介／お知らせ（一覧・記事4件）

## 作りのポイント
- **症状から探す**: からだの図の丸を押しても、「場所」のボタンを押しても同じように選べる（両方が連動）。症状を選ぶと、考えられる主な病気がその場で絞り込まれ、件数を読み上げる。詳しいページがある病名はリンクになる。図の丸は押せる大きさ（44px）を確保したボタン
- **今日の診療時間と受付状況**: 時間表の今日の列を色で示し、端末の時刻から「午前の受付中」「午後は 15:00 から」「本日の受付は終了（明日は 9:00 から）」「本日休診」を表示。タブで担当医の表に切り替えられる（矢印キー・Home・End でも操作できる）
- **院で書き換えるのは 1 ファイルだけ**: 診療時間・担当医・臨時休診・祝日・症状と病名は `src/public/assets/js/data.js` にまとめた。臨時休診を足すと、2 週間前からヘッダーの上に帯が出て、当日は「本日休診」になる
- **医療広告ガイドラインに沿った文言**: 体験談・「最新」「No.1」・他院との比較は使わず、自費の検査・文書料は内容と料金をセットで表にした。院長は架空の人物のため、写真ではなく似顔絵のイラストにしている
- **スマホ**: 画面下に「Web 予約・電話・アクセス」のバーを固定。料金表はスマホでカード状に組み替える。記事の目次は PC では右に追従し、今読んでいる見出しを示す
- **アクセシビリティ**: 文字と背景のコントラストはすべて 4.5:1 以上。メニュー・予約・写真の拡大はダイアログで、閉じたら押したボタンにフォーカスを戻す。JavaScript が動かない環境でも、診療時間・担当医・部位ごとの病気がすべて読める
- **納品しやすい形**: 素の HTML / SCSS（FLOCSS）/ JavaScript。ビルド結果は圧縮なし・固定ファイル名・相対パスで、`dist/index.html` を直接開いても動く

## 診療時間・休診日の変え方（院の方向け）
`src/public/assets/js/data.js`（ビルド後は `dist/assets/js/data.js`）だけを書き換えます。
- **臨時休診**: `closed` に 1 行足す。1 日休みは `{ date: '2026-10-17', reason: '院長の学会出席のため' }`、午後だけなら `slots: ['午後']` を足す。2 週間前からページの上に帯が出て、当日は「本日休診」になる
- **祝日**: 毎年 1 回、`holidays` に翌年分を足す（内閣府「国民の祝日」で確認）
- **診療時間・担当医**: `slots` の時刻・曜日・`doctors` を直す。フッター・メニュー・注記の時間と休診日の文も自動で変わる
- 日付は `'YYYY-MM-DD'`（月・日は 2 けた）、時刻は `'HH:MM'`。書き間違いはブラウザのコンソールに警告が出て、その項目だけ使われない
- JavaScript が動かない環境のための代わりの文（`index.html`・`doctor.html` の `data-hours` の中）は HTML に直接書いてあるので、時間や担当医を変えたらそこも直す
- 受付状況は日本時間で判定し、開いたままのページも 1 分ごとに更新する

## 開発
```bash
npm ci
npm run dev
npm run build    # dist/ に出力
```

動作の確認は `30_engineering/tools/site-check`（全ページ・全リンク・はみ出し）＋ `scripts/check-flows.mjs`（症状から探す・受付状況・タブ・予約・メニュー・写真の拡大・絞り込み・JS なし）。

## 素材
- 写真: すべて [Pexels](https://www.pexels.com/ja-jp/license/)（商用利用可・クレジット表記不要）。出典の一覧は `src/assets/images/SOURCES.md`
- アイコン・似顔絵・背骨の図・地図: SVG で自作
- 医療機関名・人物・住所・電話番号・料金はすべて架空です

## デモとしての扱い
- 架空の医療機関なので `noindex`（検索に出さない）。sitemap は置かない
- Web 予約はダイアログで「デモのため予約できません」と出すだけ。実際の院では予約システムの URL にリンクする
- アクセス解析（GA4）は入れていない。実案件では計測タグと予約ボタンのクリック計測を足す
