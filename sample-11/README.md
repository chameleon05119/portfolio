# sample-11：採用LP（ひより訪問看護ステーション）＋広告バナー

架空の訪問看護ステーションが、看護師（常勤・パート）を募集する 1 ページの採用 LP と、同じトーンの広告バナー 3 サイズ（スマホ用は 2 倍の画像も。PNG は 4 枚）です。構成・デザインからコーディングまで自作しました。

## ページ
- `index.html` … 採用 LP（最初の画面／お悩み → 解消／数字で見る／働き方 POINT 01〜04／1日の流れ／給与の目安／先輩の声／歓迎する方／募集要項・入職までの流れ／よくある質問／見学・応募フォーム）
- `banners/index.html` … 書き出した広告バナーの一覧（ダウンロードできる）
- `banners/source.html` … バナーの原稿（実寸の HTML。`npm run banners` がここを撮影して PNG にする）

## 作りのポイント
- **お悩み → 解消**: 「ひとりで訪問するのが不安」などを押すと、ひよりでの答え（POINT 01〜04）が光り（読み上げでは「あてはまる：」を付ける）、答えを押すとその説明へ移動する
- **1日の流れ・募集要項のタブ**: 常勤／パート／入職1か月目を切り替える。矢印キー・Home・End でも操作でき、タイムラインは上から順に現れる
- **給与の目安**: 働き方・経験・オンコールの回数（パートは週の日数も）で月収の目安と内訳を出す。「この条件で見学を申し込む」で、条件を応募フォームの質問欄に入れる。結果はスライダーが止まってから 1 回だけ読み上げる。募集要項の給与（月給31万〜35万円・週3日から）と同じ範囲になるようにした
- **応募フォーム**: ページの中で 入力 → 確認 → 完了 を切り替える。エラーは送信時（件数も表示）と、入力のある項目から離れたときに出し、直した時点で消す。電話番号は全角の数字やハイフンでも受け付けて半角にそろえる。確認画面から「修正する」で戻っても入力は残る（デモのため送信はしない）
- **スマホ**: 画面下に「電話」「見学・応募する」を固定し、応募フォームが見えている間は隠す。メニューは `<dialog>` で、背面を操作できなくし、閉じたら押したボタンにフォーカスを戻す（メニュー内のリンクで移動したときは、移動先にフォーカスを移す）
- **広告バナー**: LP と同じ色・文字・写真で 1080×1080／1200×628／320×100（＋640×200）を HTML で組み、`npm run banners` で PNG に書き出す。文言や写真を変えても書き出し直すだけで 3 サイズがそろう
- **JavaScript が動かないとき**: タブの中身は見出しつきで全部並べ、ふわっと表示もしない。送信ボタンは押せないままにする
- **文言**: 求人の表現として「必ず」「No.1」「いつでも」などの言い切りは使わない。数字は母数をそろえる（「看護師12名中10名」）。数字・人物・事業所はすべて架空と、最初の画面の帯・先輩の声・フッターに書いた

## 数字・料金を変えるとき
- 給与の目安の計算に使う数字は `src/public/assets/js/main.js` の `SALARY` にまとめた（基本給・時給・手当）。募集要項の表（`index.html`）も合わせて直す
- 最初の画面の数字バッジ・「数字で見る」は `index.html` に直接書いてある（`data-to` がカウントアップの最終の数字）

## 写真の差し替え
写真の原本は `src/assets/images/source/` に置き、`npm run photos` で切り出しと WebP の幅違いを作る（ファイル名は `scripts/prepare-photos.mjs` の一覧）。原本を差し替えて実行し直すだけでよい。そのあと `npm run banners` でバナーも作り直す。

## 開発
```bash
npm ci
npm run dev
npm run build      # dist/ に出力
npm run photos     # 写真の切り出し（原本を替えたとき）
npm run banners    # 広告バナーを PNG に書き出す（ビルドも行う）
npx vite build && node scripts/check-flows.mjs   # 動く部品の確認（51 項目）
```

## 外部の読み込み
- 見出し・数字・英字の書体は Google Fonts から読み込む（M PLUS Rounded 1c・Kalam・Outfit）。ネットにつながらない環境ではシステムの書体で表示される。実際の案件で外部への接続を避けたいときは、書体のファイル（woff2）を `src/assets/fonts/` に同梱する

## 素材
- 写真: Google の画像生成 AI（Gemini）で作成した架空の人物・場面（`src/assets/images/SOURCES.md`）
- アイコン・ロゴ・地図: SVG で自作
- 事業所名・人物・住所・電話番号・給与などの数字はすべて架空です

## デモとしての扱い
- 架空の事業所なので `noindex`（検索に出さない）
- 応募フォームは送信しない。実際の案件では、送信先（フォームのサービスやメール送信の仕組み）と、送信完了の計測（GA4 など）を足す
