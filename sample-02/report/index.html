対応範囲

  • 対象: トップページ（index.html / css/style.css）
  • 切り替え幅: 959px 以下をタブレット・スマホ、599px 以下をスマホとして調整。960px 以上（PC、iPad 横向きを含む）は従来どおりの表示
  • HTML の変更: viewport の追加／価格表のカード表示のため thead・tbody と各セルの項目名（data-label 属性）を追加／地図の大きさをインライン style から CSS へ移動
  • CSS の変更: 既存の記述は地図の大きさの移動のみ。末尾に「スマホ・タブレット対応」のブロックを追加（PC 用の指定をこのブロックで上書き）
  • 確認環境: Google Chrome のスマホ・タブレット表示（エミュレーション）で 320 / 375 / 414 / 600 / 768 / 900 / 959px、PC 表示で 960 / 1024 / 1280 / 1440px。あわせてスマホの実機で表示・操作を確認（2026-10-03）

01スマホで PC 表示がそのまま縮小され、文字が読めない

原因
viewport の指定がなく、スマホのブラウザが幅 980px 以上の PC 表示として描画して縮小している
修正
<meta name="viewport" content="width=device-width, initial-scale=1"> を追加し、959px 以下では固定幅（960px）をやめて画面幅に合わせて伸縮するよう変更
確認幅
375px

02ヘッダーのメニューが小さく、タップしにくい（タブレット・スマホ）

原因
固定高さ 80px のヘッダーに、ロゴ・メニュー5項目・電話番号を横並びで詰めている。メニューの文字は 13px で、PC 表示が縮小されるとさらに小さくなり、指で押せる大きさにならない。固定幅を外すだけでは、768px 前後で電話番号がヘッダーからはみ出す
修正
959px 以下ではヘッダーの固定をやめ（ロゴ・メニュー・電話番号を並べると高さが約160px になり、固定すると画面を圧迫するため）、メニューを高さ 44px のボタン状に並べる（タブレット5列・スマホ3列）
確認幅
768px

03メインビジュアルの高さと背景の指定が、スマホ・タブレットで意図どおりに表示されない

原因
高さを画面の高さ（100vh）に固定したうえで、背景を固定表示（background-attachment: fixed）している。背景の固定表示は多くのスマホのブラウザで期待どおりに動かず、写真が意図より大きく拡大されて表示されることがある。修正前の画像は Chrome のスマホ表示での再現のため、背景の拡大は写っていない
修正
959px 以下では高さを内容に合わせ、背景の固定表示を解除
確認幅
375px

04画像と文章の横並びが崩れる（スマホ・タブレット）

原因
画像（幅 480px）と文章（幅 440px）を float で左右に並べている
修正
959px 以下では画像と文章を縦に並べ、画像は画面幅に収まるよう縮小（img に max-width: 100%）。画像はタブレット幅（768px）での表示
確認幅
768px

05価格表が横にはみ出し、内容が読めない

原因
表の幅が 960px 固定で、セル内の改行も禁止（white-space: nowrap）している
修正
599px 以下では1商品ずつのカード表示に切り替え、各セルに付けた項目名（data-label）を値の左に表示。タブレットでは表のまま画面幅に合わせ、セル内の改行を許可
確認幅
375px

06お知らせとサイドバーの2列が崩れ、URL が枠からはみ出す

原因
本文（620px）とサイドバー（300px）を float で2列にしている。Instagram の長い URL は途中で改行されないため、PC でも枠からはみ出していた
修正
959px 以下ではサイドバーを本文の下へ。長い URL・メールアドレスは、収まらないときだけ途中で改行する（body に overflow-wrap: break-word。PC にも適用）
確認幅
375px

07地図が画面からはみ出し、住所・メールアドレスが読めない

原因
地図の大きさが HTML のインライン style で 600×400px に固定されている
修正
インライン style を CSS に移し、959px 以下では画面幅に合わせて縮小。住所は地図の下に表示
確認幅
375px

08フォームがはみ出し、入力しようとすると画面が拡大される

原因
表の幅 700px・入力欄の幅 480px が固定。また入力欄の文字が 13px で、iPhone（iOS Safari）は文字が 16px 未満の入力欄を選ぶと画面を自動で拡大する仕様のため、入力のたびに拡大・縮小が必要になる
修正
599px 以下では項目名を入力欄の上に置き、入力欄を画面幅に。959px 以下では入力欄の文字を 16px に
確認幅
375px

09フッターのリンクが小さく、隣のリンクを押し間違える

原因
11px の文字のリンクを「|」区切りで1行に並べており、タップできる高さが約11px
修正
959px 以下ではリンクの文字を 14px、タップ領域を高さ 44px 以上に。スマホでは1項目ずつ縦に並べる
確認幅
375px

補足・ご提案

  • ヘッダーの固定（追従）は 959px 以下でやめています。ページ下部からメニューに戻るには上までスクロールが必要です。追従させたい場合は、ヘッダーを細くして固定する方法か、ハンバーガーメニュー（JavaScript を追加）をご提案できます
  • スマホの価格表はカード表示のため表の構造（thead・tbody）を display: block にしており、スクリーンリーダーでは表として読み上げられません。各セルの項目名は表示されるため内容は伝わりますが、表としての読み上げが必要な場合は ARIA 属性の追加で対応できます
  • 960px 以上のタッチ端末（iPad の横向きなど）は PC と同じ表示です。入力欄の文字（13px）による拡大は iPad では起きにくいですが、気になる場合は PC の入力欄も 16px にすることをおすすめします
  • PC のフッターの文字（11px）とロゴの「BAKERY」（11px）は、PC の見た目を変えない方針のため変更していません。読みやすさのため 12px 以上への変更をおすすめします
