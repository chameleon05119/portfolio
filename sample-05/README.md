# sample-05：サービス紹介 LP（BtoB SaaS・ギジレコ）

架空の AI 議事録ツール「ギジレコ」のランディングページです。構成・デザインからコーディングまで自作しました。

## ページ
LP（トップ）／資料ダウンロード・お問い合わせ（入力・確認）／送信完了／個人情報の取り扱い

## 作りのポイント
- **納品しやすい形**: 素の HTML / SCSS（FLOCSS）/ JavaScript。ビルド結果は圧縮なし・固定ファイル名・相対パスで、`dist/index.html` を直接開いても動く
- **画像を使わない画面イメージ**: 最初の画面の管理画面と、機能カードの中の小さな画面は、すべて HTML/CSS で組んでいる。軽く、拡大してもぼやけず、文言も HTML で直せる。録音の波形が動き、要約 → ToDo → 共有の順に現れる
- **国内 BtoB LP の王道の構成**: お悩み → 解決（これまで／導入後）→ 機能 → 数字で見る効果 → 導入事例 → 使い方 → 料金 → セキュリティ → よくある質問 → 資料ダウンロード
- **資料ダウンロードへの導線**: 表紙つきのボタン（最初の画面）、ヘッダーに常に表示、スマホでは最初の画面を過ぎたら画面下にボタンを追従（ページ最後の CTA が見えたら隠す）
- **料金表**: 月払い／年払いで金額が切り替わる（読み上げでも切り替えを知らせる）。スマホでは人気プランを先頭に。機能の比較表は開閉式
- **フォーム**: ご用件（資料ダウンロード／無料トライアル／ご相談）を選べ、ご相談のときだけ「ご相談内容」が必須になる。入力し終えた項目からその場で確認し、送信時はエラーを一覧にして各項目へ移動できる。確認画面 → 完了画面で資料（PDF）をダウンロード。「お問い合わせ」「無料でためす」から来たときはご用件を自動で選ぶ
- **ヘッダーは最小限**: LP の PC 幅だけページ内リンクを置き、スマホはロゴだけ（資料ダウンロードは画面下の追従ボタンで押せる）。フォームのページはナビを置かず、ロゴと「サービス紹介に戻る」だけにして、入力の途中で離れにくくしている
- **アクセシビリティ**: JavaScript が動かない環境でも LP の内容はすべて読める（料金は年払いで表示、フォームは案内を表示）
- **動き**: スクロールでの表示、数字のカウントアップ、ロゴの帯、FAQ のなめらかな開閉。ロゴの帯はボタンで止められる。OS の「視差効果を減らす」設定では止める

## 開発
```bash
npm ci
npm run dev
npm run build    # dist/ に出力
```
